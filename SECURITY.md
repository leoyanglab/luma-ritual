# Security

Do not commit `.dev.vars`, environment files, administrator passwords, order receipt tokens, or Cloudflare credentials.

Do not post credentials or private order data in public issues. For a suspected security issue, contact the repository owner through their GitHub profile rather than publishing an exploit with access-bearing details.

This project is a fictional storefront demo. It does not process real payments or fulfill orders. The owner authentication is a single shared administrator password, not a multi-user identity or role system.
